## What the run shows

The `8,192 × 1,024` input passed correctness on both cards. It slowed by **7.63% on the RTX 4090** and **2.95% on the A100 SXM4**, inside the ±5% tolerance on the A100. On the `257 × 1,000` input, both cards regressed. WarpDiff failed the GitHub check based on those timing intervals.

The two showcase rentals recorded **62.00 CUDA-timed GPU minutes**. Vast billed **$0.572** for those two rentals and **$0.683** for all four WarpDiff rentals, including the initial review. Cleanup was verified. The screenshot was generated by the GitHub workflow after the run, before the provider charges settled. The hosted report has the updated charges.

How the check works

Set up WarpDiff in your repo ↗ See the example repo ↗

  1. Check the outputs

    WarpDiff reads the GPU models and cases from your repo, then compares both versions with the same reference on each GPU.

  2. Time both versions

    It times the original and patched kernels in pairs and randomizes which version goes first.

  3. Decide whether the patch is slower

    The check flags a regression when the entire 95% confidence interval is above the cutoff. The report also shows the charges Vast posts after the rentals are deleted.

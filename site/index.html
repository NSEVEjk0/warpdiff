How WarpDiff tests a patch

Check the outputs

WarpDiff compares both versions with PyTorch on each GPU before timing them.

Time the kernels

WarpDiff times both versions in pairs and randomizes which goes first. It flags a slowdown if the entire 95% confidence interval is above the cutoff.

End the rentals

After the run, WarpDiff deletes the rentals and lists the charges Vast has reported.
